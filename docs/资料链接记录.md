- **活动**：上海交通大学学生创新中心首届面向教职工子女的「科创冬令营」

  1. VEX 机器人科创实践（VEX V5 + Kiwi 三轮全向底盘，C++）
  2. 人形机器人趣味编程与实践（幻尔 TonyPi-Pro，Python / 视觉 / 语音 / 大模型）
  3. 智能交互应用（香橙派 AIpro，语音助手 + 人脸手势识别 + 大模型，多模态 AI 应用）
  4. 无人机设计与制作（设计—制造—调试—飞行—应急物资投送赛）
  5. 食品安全探究与实践（酶催化显色、微生物培养、理化滴定、花青素新鲜度指示卡）
